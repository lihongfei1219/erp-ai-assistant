# 项目进度与下一步

更新：2026-09-20。这里是进度的唯一维护入口；功能操作和验证证据分别链接到专门文档。

## 当前结论

已完成可在本机运行的只读销售分析助手：网页和飞书共用自然语言计划、确定性计算及统计口径。飞书统一卡片展示已启用。当前处于内部试用阶段，数据仍来自历史备份，尚未达到持续更新、正式权限和进程守护齐备的生产部署状态。

用户当前范围是“通过自然语言获取数据分析结果”，不执行 ERP 业务操作。今日Top 5、运营待办、业务写入不列入近期实施。

## 已完成与验收边界

| 模块 | 当前进度 | 仍需关注 |
|---|---|---|
| 数据接入 | SQL Server恢复库只读取数、主明细对账、不可覆盖快照 | 尚无自动增量同步 |
| 业务口径 | 原始订单／暂定有效销售分离，Decimal四位精度，规则版本与指纹 | 支付退款事实尚未接入 |
| 网页 | 经营概览、订单明细、业务口径、飞书日报、AI数据分析 | 本地开发令牌，未接正式SSO |
| 自然语言 | 概览、趋势、客户排行、商品排行、期间比较、日波动；支持组合与计划追问 | 受控能力，不支持任意条件；分类、数量、利润、库存未接入 |
| 飞书问数 | 应用机器人长连接、群／用户白名单、持久任务和发件箱、30分钟追问 | 需电脑和进程持续运行 |
| 飞书展示 | 卡片2.0、图表、分页表格、折叠说明、空数据和容量降级 | 本地预览通过；新版实际客户端视觉验收待确认 |
| 日报 | 预览、Webhook发送实现、独立08:00调度入口 | 未启用实际定时推送，缺每日完整新数据 |
| 工程验证 | 后端、浏览器、助手库、真实模型合成评测均有记录 | 未建立CI和生产压测基线 |

“卖得好”默认金额前10；用户已确认“药品”泛称按当前商品范围分析并标注未做类别筛选。显式要求“只看药品／排除器械”不能忽略。订单金额不是支付成交额，未扣退款。

## 下一步顺序

| 优先级 | 工作 | 完成标准 |
|---|---|---|
| P0 | 飞书真实客户端走查 | 同一组概览、排行、趋势、比较和组合问题，在桌面／手机确认可读、数值和范围一致 |
| P0 | 形成真实问法评测集 | 用脱敏问题记录预期计划、澄清条件和追问结果；以后改模型或提示词都跑回归 |
| P1 | 持续更新数据 | 确认授权源、增量水位和删除／历史修正语义；定时生成对账通过的新快照，显示新鲜度 |
| P1 | 运行维护 | 单实例进程守护、重启恢复、日志轮转、助手库备份／保留期、告警；CI执行离线检查 |
| P1 | 正式访问控制 | 接平台账号、SSO及数据范围；查询、证据、导出和报告链接采用一致权限 |
| P2 | 扩展分析维度 | 在字段映射和口径确认后接商品分类、指定对象筛选，再考虑库存／利润等事实 |

先完善试用质量和数据更新。没有性能实测依据时继续使用Pandas，不预先增加分布式计算、多Agent或额外队列系统。

## 文档与文件维护

文档收敛为10份：本页、架构、4份使用说明、3份数据口径文档和1份验证记录。已完成的阶段计划、重复设计及分散验证记录合并后删除，不再每轮新增一份计划和一份验收文档。只有新增独立子系统且确需单独设计时才增加文档。

`.local/`不是可以整体删除的缓存目录：其中包含访问令牌、飞书凭据、进程锁、去重状态和真实快照。仅清理明确可重建的测试临时目录、截图、HTML／JSON预览、文档抓取副本及依赖下载缓存。保留源代码、锁定依赖、已安装环境、运行中的前端构建、数据库备份与安装介质。

本次已清理21,721个可重建文件，逻辑大小约377MiB；保留65个被运行中服务占用的uv缓存文件（约43.7MiB）。135个受保护文件哈希未变，已有服务健康检查通过。清理命令及复查方法见[验证记录](validation.md)，本机汇总及最近批次明细保存在`.local/maintenance/cleanup-last.json`；不包含密钥或业务记录。
