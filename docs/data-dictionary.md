| 标准字段 | 源字段 | 源类型 | 定义与约束 |

| `amount` | `XSDDH.ZJE` | numeric(18,4) | ERP 表头总金额，原始四位精度 |
| `order_id` | `XSDDB.DjLsh` | int | 与表头一对多关联 |
